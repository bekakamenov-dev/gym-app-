# Зал Бексултана

Личное приложение для тренировок по программе Full Body A / B / C.
Работает на iPhone как приложение с экрана «Домой» (PWA).

## Файлы

- `index.html` — всё приложение: экраны, программа тренировок, логика.
- `manifest.webmanifest` — название и иконка для экрана «Домой».
- `sw.js` — позволяет открывать приложение без интернета.
- `icon-*.png` — иконки.

## Где данные

Тренировки и вес тела хранятся в самом iPhone (в Safari).
Резервная копия: «История» → «Сохранить копию».

## Как поменять программу

В `index.html` найди `const PROGRAM`. Там упражнения: `s` — подходы, `r` — повторы,
`rest` — отдых в секундах, `step` — шаг веса, `w0` — стартовый вес.
После правок в `sw.js` увеличь номер в `CACHE = "zal-v1"`.
